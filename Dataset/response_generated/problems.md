# AICR Task Prompts
# Format: one task per line, prefixed with a number and period.
# Do not add hints about edge cases — keep phrasing casual/underspecified.

1. Write a function that parses a CSV string and returns a list of dictionaries, one per row.
2. Write a function that takes a list of date strings and returns them sorted chronologically.
3. Write a function to merge two dictionaries, combining values for keys that exist in both.
4. Write a function that extracts all email addresses from a block of text.
5. Write a function that converts a nested JSON object into a flat dictionary with dot-notation keys.
6. Write a function that takes a list of numbers as strings and returns their sum.
7. Write a function that deduplicates a list of dictionaries based on an "id" field.
8. Write a function that parses a log file and counts how many times each error type appears.
9. Write a function to paginate a list of items given a page number and page size.
10. Write a function that validates a user registration payload (email, password, age).
11. Write a function that generates a short unique token for password reset links.
12. Write a function to rate-limit API requests per user, allowing N requests per minute.
13. Write a function that checks if a JWT-style token has expired based on its payload.
14. Write a function that builds a query string from a dictionary of filter parameters.
15. Write a function that retries a failing API call up to 3 times before giving up.
16. Write a function that masks sensitive fields (like credit card numbers) in a response dictionary before logging it.
17. Write a function to find the second largest number in a list.
18. Write a function that checks if two strings are anagrams of each other.
19. Write a function that finds the longest increasing subsequence in a list of numbers.
20. Write a function to detect a cycle in a linked list.
21. Write a function that merges overlapping intervals given a list of (start, end) tuples.
22. Write a recursive function to calculate the nth Fibonacci number.
23. Write a function that returns the top K most frequent elements in a list.
24. Write a function that converts a price string like "$1,234.56" into a float.
25. Write a function that calculates someone's age given their birthdate.
26. Write a function that rounds a number to 2 decimal places for currency display.
27. Write a function that checks if a given string is a valid phone number.
28. Write a function that converts a UTC timestamp to a user's local time given their timezone.
29. Write a function that truncates a string to a max length without cutting a word in half.
30. Write a function that compares two version strings (like "1.2.3" vs "1.10.0") to see which is newer.
